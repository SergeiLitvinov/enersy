## 2026-10-30 — единицы при создании из проектного паспорта

Новые экземпляры фиксируют непустые единицы параметров выбранной версии паспорта проекта в общей транзакции создания. Дополнительные переопределения и пустые единицы не получают выдуманную паспортную декларацию. HTTP 201, клиентский парсер, приватный транспорт и состояние редактора передают ту же декларацию до следующего чтения графа. [Правила копирования](./numerical-validation.md#instance-unit-declarations).

Прошли полный Go vet/build/race-набор: 142 верхнеуровневых теста, 6 прежних opt-in пропущены; frontend typecheck/lint/build и 562 теста, 1 прежний opt-in пропущен. Go-линтер — 0 замечаний. Отдельный реальный `TestCalculationArchiveWorkerPostgres` подтвердил физический результат и архив после смены единицы шаблона генератора на W: экземпляр использовал МВт из паспорта вместе с явным переопределением значения. Сохранились точные байты входа/результата и происхождение; невязки баланса P/Q — порядка 1e-14 МВт/Мвар.

Проверены также HTTP-подтверждение единиц, повторное чтение графа, несвязанность нового экземпляра со следующей версией паспорта, отказ новой привязки при несовместимом шаблоне и полный rollback компонента при поздней ошибке хранения единицы. Визуальная приёмка подписей остаётся отдельным незавершённым пунктом CORE-01. Проверки использовали одноразовый Docker-стенд; рабочие данные не изменялись. Локальные логи — `.cache/passport-unit-copy-*.log`.
