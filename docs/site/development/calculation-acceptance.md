# Приёмка исходных замечаний A01–A08

Контур BASE-01 проверяет безопасность и воспроизводимость существующего расчётного пути. Он не подтверждает всю физику энергосистемы: общий AC-профиль остаётся `experimental`, фазный расчёт и динамика здесь не реализованы. Исходные замечания сохранены в [анализе проекта](/generated/review).

## Карта регрессий

Пути ниже указаны относительно `backend-julia/test/`; все файлы входят в `runtests.jl`.

| Замечание | Проверяемое поведение | Регрессии |
| --- | --- | --- |
| A01: отсутствовал Slack | Питаемый остров получает опорный источник; независимые острова решаются отдельно с происхождением узлов | `islands.jl`: `Independent powered islands retain physical provenance`; `compiled_network_reference.jl`: многoисточниковые сети PYPOWER |
| A02: размеры уравнений и Якобиана | Согласованы неизвестные и уравнения, производные совпадают с центральной разностью; sparse-путь воспроизводит независимые сети | `runtests.jl`: `Power flow setup cannot bypass validation`, `Jacobian agrees with finite differences at nonzero angles`; `sparse_solver.jl`; `ac_reference.jl` |
| A03: пропадали связи через оборудование | Цепь источник–выключатель–шина–линия–нагрузка компилируется по терминалам; открытый аппарат и неверный порт меняют топологию либо диагностируются | `runtests.jl`: `Compiled terminals and full result`; `terminal_provenance.jl`; `islands.jl`; `compiled_network_reference.jl` |
| A04: фиктивные проводимости и прямой режим | Пассивные элементы не генерируют энергию; баланс сходится, пропущенные данные не подменяются; прямой сетевой режим отклоняется HTTP 422 | `runtests.jl`: `Passive equipment rejects artificial energy generation`, `Transformer and branch energy`; `model_parameters.jl`; `http_acceptance.jl` |
| A05: единицы и знаки | Явные базисы, аналитическая двухузловая сеть, баланс нагрузки/источника и потерь; устойчивый переход базиса с независимой арифметикой | `runtests.jl`: `Units and input contract`, `Analytical two-bus load flow`; `base_scaling.jl`, `own_base_scaling.jl`, `compiled_reference.jl` |
| A06: неверная фазная постановка | Запрос фазного Ньютона отклоняется до расчёта со статусом 422 и `unsupported_method` | `http_acceptance.jl`; `runtests.jl`: `HTTP contract and real socket`. Это устранение выдачи ложного результата, не реализация фазного метода (PHY-01) |
| A07: JSON3 и строгие сигнатуры | Реальные JSON-запросы пересекают сетевую границу; неверные типы и размеры дают структурированный отказ; следующий корректный запрос успешен | `http_acceptance.jl`: `Historical audit: real HTTP rejection and recovery`; `runtests.jl`: `HTTP contract and real socket` |
| A08: сервер стартовал до определений | Импорт пакета возвращает управление тестам; сервер запускается явно на случайном loopback-порту, обслуживает оба маршрута и закрывается в `finally` | Точка импорта `runtests.jl`, `http_acceptance.jl`, `runtests.jl`: `HTTP contract and real socket`; серверный entrypoint отделён от модуля |

Новая сетевая проверка охватывает не-объект JSON, пустую, рваную и неквадратную матрицу, пустой/несовместимый вектор, неверные элементы матрицы/вектора и ID оборудования. Проверяются HTTP-статус, JSON, категория и код ошибки; после каждого неверного линейного запроса выполняется корректный. Успешный `/calculate` проверяет невязки активного и реактивного баланса менее 10⁻⁶ МВт/Мвар. `/solve` проверяется по независимому решению x=[−0,2; 1,8], допуск 10⁻¹². Этот служебный LU-маршрут не является расчётом режима сети.

## Подтверждённый прогон

2026-10-21: полный `test/runtests.jl` завершился с кодом 0 в Docker с ограничением 2 CPU / 2 ГиБ и отключённой внешней сетью. Новый набор сетевого отказа/восстановления прошёл 71 утверждение; существующий HTTP-набор — 23. Также прошли независимые AC-эталоны, проверки компиляции оборудования, островов, ZIP, фазосдвига, Q-ограничений и базисов. Эти результаты закрывают контур BASE-01, но не CORE-05/07 или PHY-01.

## Воспроизводимый запуск

Из корня репозитория, без вручную запущенного HTTP-сервера:

```powershell
docker compose build julia-compute
docker run --rm --cpus 2 --memory 2g --network none --mount type=bind,source="${PWD}/backend-julia",target=/app,readonly enersy-julia-compute julia --project=. --startup-file=no test/runtests.jl
```

Контейнер не имеет внешней сети, реальные HTTP-запросы используют его loopback. Доступ к рабочей БД не нужен. Проверки возвращают ненулевой код при отказе; в CI запускается этот же `runtests.jl` через `Pkg.test()`. Локальный прогон не доказывает успешный удалённый CI. Лицензии, генераторы и допуски независимых наборов описаны в `backend-julia/test/reference/README.md` и [численной верификации](./numerical-validation.md); единый расширенный отчёт остаётся задачей CORE-07.
