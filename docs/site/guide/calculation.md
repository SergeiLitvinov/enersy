# Расчёт и ошибки

Пассивные модели линии и сопротивления источника отклоняют отрицательные
активные сопротивления; линия также отклоняет отрицательную активную
проводимость. Число параллельных цепей должно быть положительным целым в
поддерживаемом диапазоне. Ошибка содержит компонент и параметр: исправьте
исходные данные перед повторным расчётом.

Заданная ЭДС генератора `e` должна быть положительной и конечной. Нулевая или
отрицательная ЭДС блокирует расчёт; она не заменяется номинальным напряжением.
Если ЭДС отсутствует, применение `voltage_nom` явно отражается в допущениях.
Каждый питаемый остров рассчитывается отдельно. При нескольких источниках
в острове выберите ровно один балансирующий генератор параметром `is_slack=true`;
остальные задают P и модуль внутренней ЭДС. Единственный источник острова
может быть выбран автоматически. После соединения островов пересмотрите выбор
балансирующего источника: два slack в одной связной сети отклоняются.
Остров без источника пока прекращает весь расчёт; обесточенный режим не подставляется.

В окне результатов для нескольких островов показаны их состав по числу узлов,
балансирующие источники, итерации и невязки. Каждый остров имеет свой опорный
угол, поэтому углы разных несвязанных островов нельзя использовать для оценки
синхронизма. Общий лимит итераций распространяется на все острова и Q-проходы.

В экспериментальном API-профиле источника можно задать пару
`q_min_emf_mvar` / `q_max_emf_mvar` — границы Q внутренней ЭДС в Мвар.
При нарушении PV переходит в PQ; Q фиксируется, модуль ЭДС становится результатом,
событие отображается в предупреждениях. Эти границы не относятся к терминалу
машины. Нарушение объявленных границ балансирующего источника прекращает расчёт.
Если после других переключений источник может снова поддерживать уставку,
он возвращается PQ→PV; возврат также отражается в предупреждениях.
Цикл переключений или исчерпание бюджета прекращает расчёт с диагностикой.
Смена балансирующего источника пока не поддержана.

Окно результатов показывает мощности внутренней ЭДС каждого генератора,
фактический режим Slack/PV/PQ, объявленный диапазон Q и состояние «На границе»,
«В диапазоне» или «Не заданы». Эти значения не являются мощностями выводов
машины: они отличаются на потери в сопротивлении источника. На узком экране
таблица источников прокручивается по горизонтали.

## Поддержанный сценарий

Панель получает доступные сочетания модели и метода из Julia через API. Сейчас выполняется только `three-phase / newton-raphson`: **симметричный AC-режим в полярных координатах**. Название группы историческое; это не расчёт трёх независимых фаз. Статус — **экспериментальный**.

Прямой метод режима, фазные координаты и симметричные составляющие отклоняются. Раздел [план работ](/generated/todo) описывает будущее развитие, а не доступные функции.

Кнопка «Возможности и ограничения расчёта» открывает перечень сочетаний модели и решателя с причинами их недоступности. Данные получены из ядра, а не из статического списка интерфейса.

## Перед запуском

Задайте параметры с единицами из шаблона: напряжение — кВ, активная мощность — МВт, реактивная — Мвар, сопротивление — Ом; для линии удельные параметры умножаются на длину. Реальные значения уточняйте в коде модели и шаблоне параметров, особенно проводимости линии. Калькулятор не заменяет проверку паспортов.

Соедините источники и потребителей через поддержанные ветви. Нужные параметры должны быть конечными числами. Неподдержанный аппарат или несовместимые уровни напряжения приводят к отказу. Наличие графического символа не означает наличие математической модели.

Ядро проверяет состав Slack/PV/PQ: каждый узел относится ровно к одной группе. Напряжения должны быть положительными и конечными, мощности, углы и проводимости — конечными. Проверка действует также при прямом вызове численного модуля разработчиком. Положительный конечный допуск и число итераций обязательны; даже одноузловая задача не возвращает успех при переполнении вычисленной мощности.

Нажмите «Рассчитать». Запрос синхронный: пауза, продолжение, checkpoint и управление длительным заданием ещё отсутствуют. API ограничивает ожидание worker 25 секундами. Отмена HTTP-запроса не гарантирует немедленного прерывания численной функции Julia.

## Результат

Напряжения узлов возвращаются в кВ, углы — в градусах; расчёт внутри ведётся в p.u. на общей базовой мощности и напряжении. В результате также возвращаются ветви, потери, баланс, число итераций, статус и предупреждения. Текущий интерфейс отображает только часть этих данных; полный JSON доступен через API.

Диалог результата показывает напряжения и углы с единицами, число узлов, итерации, время и предупреждения о границах применимости. Данные проходят проверку типов и конечности чисел перед отображением. При ошибке постоянное сообщение остаётся под панелью расчёта; уточнение содержит идентификатор проблемного объекта, если ядро его сообщает.

Источник представляется ЭДС за сопротивлением с внутренним slack/PV-узлом, а не полноценной динамической моделью машины. Поддержан описанный выше профиль Q-границ внутренней ЭДС; терминальные ограничения машин пока не применяются. Плотные матрицы ограничивают масштаб; пригодность для крупных сетей ещё не измерена.

## Если расчёт не удался

| Диагностика | Действие |
| --- | --- |
| Неподдержанный метод или элемент | Выберите доступный сценарий; соответствующая функция остаётся в плане |
| Недостающий / недопустимый параметр | Проверьте объект, единицу и поле, указанные в сообщении |
| Остров без источника | Проверьте порты, провода и состояние аппаратов |
| Вырожденная матрица | Проверьте топологию и физическую постановку; не заменяйте ошибку нулевыми результатами |
| Несходимость | Проверьте нагрузку и параметры; увеличение числа итераций само по себе не доказывает существование решения |
| API / worker недоступен | Проверьте готовность контейнеров и журнал |
