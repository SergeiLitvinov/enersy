# Расчёт и ошибки

## Поддержанный сценарий

Панель получает доступные сочетания модели и метода из Julia через API. Сейчас выполняется только `three-phase / newton-raphson`: **симметричный AC-режим в полярных координатах**. Название группы историческое; это не расчёт трёх независимых фаз. Статус — **экспериментальный**.

Прямой метод режима, фазные координаты и симметричные составляющие отклоняются. Раздел [план работ](/generated/todo) описывает будущее развитие, а не доступные функции.

Кнопка «Возможности и ограничения расчёта» открывает перечень сочетаний модели и решателя с причинами их недоступности. Данные получены из ядра, а не из статического списка интерфейса.

## Перед запуском

Задайте параметры с единицами из шаблона: напряжение — кВ, активная мощность — МВт, реактивная — Мвар, сопротивление — Ом; для линии удельные параметры умножаются на длину. Реальные значения уточняйте в коде модели и шаблоне параметров, особенно проводимости линии. Калькулятор не заменяет проверку паспортов.

Соедините источники и потребителей через поддержанные ветви. Нужные параметры должны быть конечными числами. Неподдержанный аппарат или несовместимые уровни напряжения приводят к отказу. Наличие графического символа не означает наличие математической модели.

Нажмите «Рассчитать». Запрос синхронный: пауза, продолжение, checkpoint и управление длительным заданием ещё отсутствуют. API ограничивает ожидание worker 25 секундами. Отмена HTTP-запроса не гарантирует немедленного прерывания численной функции Julia.

## Результат

Напряжения узлов возвращаются в кВ, углы — в градусах; расчёт внутри ведётся в p.u. на общей базовой мощности и напряжении. В результате также возвращаются ветви, потери, баланс, число итераций, статус и предупреждения. Текущий интерфейс отображает только часть этих данных; полный JSON доступен через API.

Диалог результата показывает напряжения и углы с единицами, число узлов, итерации, время и предупреждения о границах применимости. Данные проходят проверку типов и конечности чисел перед отображением. При ошибке постоянное сообщение остаётся под панелью расчёта; уточнение содержит идентификатор проблемного объекта, если ядро его сообщает.

Источник представляется ЭДС за сопротивлением с внутренним slack-узлом, а не полноценной динамической моделью машины. Ограничения Q PV-узлов не применяются. Плотные матрицы ограничивают масштаб; пригодность для крупных сетей ещё не измерена.

## Если расчёт не удался

| Диагностика | Действие |
| --- | --- |
| Неподдержанный метод или элемент | Выберите доступный сценарий; соответствующая функция остаётся в плане |
| Недостающий / недопустимый параметр | Проверьте объект, единицу и поле, указанные в сообщении |
| Остров без источника | Проверьте порты, провода и состояние аппаратов |
| Вырожденная матрица | Проверьте топологию и физическую постановку; не заменяйте ошибку нулевыми результатами |
| Несходимость | Проверьте нагрузку и параметры; увеличение числа итераций само по себе не доказывает существование решения |
| API / worker недоступен | Проверьте готовность контейнеров и журнал |

## Что проверено

`backend-julia/test/runtests.jl` содержит аналитический двухузловой эталон, независимую проверку Якобиана конечными разностями, преобразования единиц, цепь с аппаратом, баланс мощности, знаки шунтов и трансформатор. Допуски заданы непосредственно в тестах. Это не полноценная валидация по IEEE-сетям и не подтверждение переходных процессов.
