# Справочник проекта

Начните с [архитектуры](../development/architecture) и [HTTP-контрактов](./http), затем выберите формат:

- [TypeScript API](/api/typescript/index.html) — функции клиента и транспортные типы, сгенерированные TypeDoc.
- [Все исходники](/generated/code/) — объявления, номера строк и код с комментариями Go, Julia, Rust, TypeScript и SQL.
- [Правила разработки](/generated/rules) — обязательные требования к физике, единицам, API, интерфейсу и проверкам.
- [План работ](/generated/todo) — критерии приёмки будущих функций.

Справочник обновляется при каждой сборке из текущего рабочего дерева. Он описывает код, а не подтверждает инженерную достоверность моделей.
